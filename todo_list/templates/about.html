About My Todo App

This is a simple Todo List application built using Django.

Features

  • Add Todo
  • Edit Todo
  • Delete Todo
  • Mark Todo as Complete
  • Search Todos
  • Pagination
  • User Login and Logout
  • User-specific Todo Lists

Django MVT

This application follows the Django Model-View-Template (MVT) architecture.

  • Model – Handles the Todo database.
  • View – Handles application logic and user requests.
  • Template – Handles the HTML presentation of the application.
